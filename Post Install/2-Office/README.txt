WinAurex OS Builder - Office Suite Installers
=============================================

This folder provides installers for office and document productivity suites:
 - LibreOffice: Powerful, free, and open-source office suite (Word, Excel, PowerPoint compatible).
 - ONLYOFFICE Desktop Editors: Modern tabbed office suite with high Microsoft Office format compatibility.
 - Microsoft 365: Official Microsoft Office setup bootstrapper.

Each script works seamlessly with WinGet (Stable and Moderate editions) with direct download fallback.
