WinAurex OS Builder - Essential System Tools
=============================================

This folder contains high-productivity system tools and utilities:
 - 7-Zip: Ultra-fast open-source compression utility (offline installer included: 7z2501-x64.exe).
 - Notepad++: Advanced text and code editor with syntax highlighting.
 - VLC Media Player: Universal media player supporting all audio and video formats.
 - Voidtools Everything: Instant, millisecond file and folder search engine for Windows.
 - Rufus: Standalone bootable USB formatting utility (offline portable binary included: rufus-3.22p.exe).
