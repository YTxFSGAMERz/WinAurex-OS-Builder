WinAurex OS Optimization & Control Suite
=========================================

This folder provides shortcuts and launchers for the full WinAurex framework:
 - Launch_WinAurex_Dashboard.cmd: Opens the reactive WPF GUI dashboard for real-time system monitoring, AI optimization, and custom tweak management.
 - Apply_WinAurex_Suite.cmd: Executes the curated safe suite, installs runtime prerequisites, and injects 1:1 mouse input, 10ms context menus, and performance power plans.
