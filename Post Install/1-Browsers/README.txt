WinAurex OS Builder - Browser Installers
=========================================

This folder provides silent, 1-click installers for top modern web browsers:
 - Brave Browser: Privacy-first Chromium browser with native ad & tracker blocker.
 - Google Chrome: Fast, universal Chromium browser.
 - Mozilla Firefox: Independent, open-source Gecko browser.

Each script first attempts native installation via WinGet (available in Stable and Moderate editions).
If WinGet is unavailable or in an offline/constrained environment, it automatically falls back to secure HTTPS direct installation.
